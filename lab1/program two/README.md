Theory

A macro constant is a symbolic name defined using the `#define` preprocessor directive in C programming. In this program, the value of PI is defined as a macro constant to make the code easier to read and maintain.

The program calculates the area of a circle using the mathematical formula:

A = πr²

where:

* `A` represents the area of the circle
* `π` (PI) is a mathematical constant
* `r` is the radius of the circle

During execution, the user enters the radius value, and the program computes the area using the formula. The use of macro constants improves code readability and avoids repeatedly writing fixed values in the program.
